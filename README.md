# dsh-paper-reader

精读一篇论文：产出结构固定、证据可追溯的中文解读报告，并基于同一份解析产物回答关于这篇论文的
问题。它是一个独立的 DSH 模式（agent preset），只在选中「论文解读」时出现。

## 安装

```bash
dsh plugin --profile web add github:TianzeLuo/dsh-paper-reader
```

1. 重启 `dsh web`（模式与根层控件都在启动期组装，热更新不生效）
2. 刷新页面

开发调试时可改装本地目录：`dsh plugin --profile web add /path/to/dsh-paper-reader`，装之前在包目录
先 `pnpm install`——本包的运行时依赖不入库。

装不上或装完没反应，看[开发文档](docs/development.md)的「验证 bundle 与 preset 组装」一节。

## 能做什么

- **解读报告**：给定一篇论文，产出结构固定、证据可追溯的中文报告；深度分速览 / 解读 / 深读三档，图表自动裁好并嵌在第一次提到它的位置。
- **论文问答**：针对同一篇论文提问，答案带 `[p.7 §3.2]` 页/章节锚点，并分清作者主张与推断。
- **同一份解析结果**：报告与问答共用一次导入的产物，所以同一篇论文里锚点始终一致。
- **输出风格**：术语首现中英对照、缩写首现展开、指标首现说清在算什么、公式写成 LaTeX。

只支持 PDF；`paper_figures` 还能按图注自动裁出图与表，一张一个 PNG。

## 用法

| 触发方式 | 位置 | 行为 |
| --- | --- | --- |
| 选择「论文解读」 | 新任务模式选择器 | 进入本模式；只有这个模式的会话看得到本插件的工具与技能 |
| 三档段控件 | 输入框工具行左侧 | 切换速览 / 解读 / 深读；每个会话独立，模型不会自行改档 |
| 直接说「把这篇论文的 3.2 节讲清楚」 | 对话 | 五个论文工具随时可用，不必先加载技能 |

关掉插件后：「论文解读」不再出现在模式选择器里，其他模式的会话与已有文件不受影响。

模块划分与关键取舍见[开发文档](docs/development.md)；已知边界的完整清单见[已知限制](docs/limitations.md)。

## 已知限制

- 首次导入每页解析两遍（本机实测 17 页约 127ms、31 页约 247ms），之后命中缓存。
- 图表区域检测是启发式的，会漏也会多框；自动裁不出来的项会如实列出，可用 `bbox` 手动裁。
- 公式上下标在纯文本抽取里会丢，本包不做公式 OCR，改为要求写 LaTeX 并回原页核对。

逐条说明与实测记录见[已知限制](docs/limitations.md)。

## 隐私与数据

- 读取：你指定路径的 PDF，以及会话 id（用于档位记录）。
- 外发：论文正文随模型请求发往 DSH 当前配置的模型端点。
- 存储：`$DSH_HOME/paper-reader/`（源文件副本、分页正文与结构化块、图形区域检测结果、档位记录）。
- 关闭后：不再注册工具与技能；已有缓存留在原处，删掉目录即清空。
