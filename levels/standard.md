### 档位定位：解读（`standard`）

解读档交付一份**能独立读懂这篇论文**的报告：问题、方法、证据、可靠性、局限都讲到，读者读完能自己复述论文在做什么、凭什么、边界在哪。这是没在控件里选过档位时的默认档。

**档位由控件选定，不由你推断，也不要从请求话术里反推**；按本档交付，用户的口吻像在要别的东西时，在导读里说一句可以换档即可。

### 篇幅与交付文件名

| 项 | 值 |
|---|---|
| 正文篇幅 | 通常 3000–6000 字（不算报告头、图注、术语表）——**参考值，不是上限** |
| 文件名 | `<简称>-解读报告.md` |
| 位置 | 当前工作目录 |

`<简称>` 用标题里一眼能认出的短名（如 `SHINE`、`ViT`），不要用 PDF 文件名；报告头里仍写论文全称。

**篇幅服从内容，不服从数字。** 该讲透的（指标在算什么、每个公式的符号、小例子走通、证据边界）一条都不能因为「怕超字数」而压缩；内容本来就紧凑时也不必硬凑到区间下限。写到明显超出区间时，先检查是不是把深读档的额外要求（训练过程逐步走、梯度回传路径、逐项消融）写了进来——那属于跑档；而不是回头删掉本该有的解释。

### 读到什么程度

**一次 `workflow` 调用，3–6 个子智能体并行分节读正文**；主智能体自己只读摘要与引言。

| 谁读 | 读什么 |
|---|---|
| 主智能体 | `paper_read` 读第 1 页摘要与 1–2 页引言，拿地图与元信息 |
| 分节子智能体（3–6 个） | 按章节各读自己那几页正文，回结构化笔记（claims / numbers / mechanism / missing），**不要让它写报告** |
| 图表子智能体（1 个） | 跑 `paper_figures`、逐张 `read_image`，回「图号 → 这张图在说什么 → 支撑哪条主张 → 裁切是否可用」 |
| 主智能体 | 笔记没覆盖而你需要的（跨节对比、术语一致性）用 `paper_search` 补，**不要凭印象补** |

- 子智能体的 prompt 必须自包含：它看不到本会话，`docId`、页码、章节标题要写进 prompt。
- 附录**只读与正文主张直接相关的部分**：正文某条主张引到附录的表或证明时，让对应分节子智能体顺带读那几页；没有这种指向就不读附录。
- 子智能体回的是笔记，成稿由主智能体做。

### 报告骨架里哪几节要加深

七部分标题与顺序固定，**不要增删、不要合并**；重心按下表分配。

| 部分 | 本档的差别 |
|---|---|
| 1 一句话总结 | 按骨架；指标首现就地解释一句 |
| 2 问题与背景 | 写清**前人三种妥协分别是什么、各自为什么不够** |
| 3 核心方法 | 报告主体：小例子要一路走到输出；每个指标说清在算什么；公式写成 LaTeX 并逐符号解释；关键设计选择给动机 |
| 4 实验与证据 | 按「观察 → 支持什么主张」写，不并列罗列；八项清单逐条交代，没报告的写「论文未报告」 |
| 5 可靠性评估 | 四层分开，所有推断标明「这是推断」 |
| 6 贡献与局限 | 作者声称 vs 实际成立；局限分论文承认的与你看出来的 |
| 7 术语表 | 正文用到的指标都要有一句解释 |

训练过程逐步走一遍、梯度怎么回传、每个设计选择的证据强度这三条属于**更深的档位**，本档不做；除非训练细节放在正文且是理解方法的前提，那时按 §3 的常规要求讲清即可。

### 执行流程

1. `paper_import` 导入；元信息以首页正文为准。
2. `paper_read` 读摘要与引言（约 2 次工具调用，不必更多）。
3. 起一次 `workflow`：按章节分 3–6 个分节子智能体，**同一个 workflow 里并行起图表子智能体**；分节子智能体的 prompt 带 `docId`、页码、章节标题与笔记 schema。图表子智能体除了「图号 → 这张图在说什么 → 支撑哪条主张 → 裁切是否可用」，还要回**图注原文**与「裁切框里有没有混进图注文字」。**不起训练与实现细节子智能体**——附录细节由相关分节子智能体顺带读。
4. 成稿写入 `<简称>-解读报告.md`；笔记里每条主张都要落进对应章节，图插在第一次提到它的段落紧后面，**图注原文写在图片下方、不要出现在 PNG 里**。
5. 核对：起一个**数字核对子智能体**，prompt 里带 `docId` 与成稿的数字清单，把每个数字回原文比对（四舍五入、单位换算、指标口径混用都在这一类），列出对不上的项；主智能体再用 `skill` 加载 `paper-verify` 自审。
6. 改完阻断项后 `present` 交付，并给一段简短导读：做了什么、最值得注意的一点、你对可靠性的判断；写明这是解读档，不要复述报告目录。
